# Bidwise

Bidwise helps SMU students plan their BOSS course bids. It browses past clearing bids, forecasts what a section is likely to clear at, and simulates whether a bid would win. Live site: https://bidwise.pages.dev

Not affiliated with SMU.

## What is in this repo

- `site/`: the website, built with Astro and Svelte.
- `model/`: the forecast fitting code (`model/forecast/`) and `build_site_data.py`, which turns a bid-results table into the JSON the site loads.
- `docs/`: how the forecast works, in a plain-language version (`model-plain.md`) and a technical one (`model-technical.md`).
- `tests/`: Python tests for the model and the site-data build, with a synthetic fixture.

## Data

The bid history comes from SMU BOSS Overall Results. That data is not included in this repo; the tests use a small made-up dataset instead. The site's data pages need that data generated by `model/build_site_data.py`.

## Run the site

```sh
cd site
npm install
npm run dev     # http://localhost:4321
npm test        # unit tests
npm run build
```

## Run the model tests

Needs Python 3.11 or newer and no third-party packages. From the repo root:

```sh
PYTHONPATH=. python3 -m unittest tests.test_forecast_fit tests.test_forecast_sim \
  tests.test_build_site_data tests.test_site_data_s1
```

## Notes

The forecast is a statistical estimate, not a guarantee. Check the official BOSS rules and your own timetable before you bid.
